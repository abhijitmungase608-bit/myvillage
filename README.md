## 🌟 वैशिष्ट्ये (Key Features)

1. **📱 मोबाइल रिस्पॉन्सिव्ह व अ‍ॅप-स्टाइल लुक (Mobile Native App Experience)**:
   - मोबाइलवर प्रत्यक्ष नेटिव्ह अ‍ॅपसारखा लुक: फिक्स्ड टॉप अ‍ॅप बार (`कोठे`), साइड ड्रॉवर मेनू, आणि खाली फिक्स्ड बॉटम नेव्हिगेशन बार (Home, Sheti, Directory, Notices, Map).
   - डेस्कटॉपवर आधुनिक आणि भव्य वेब पोर्टल लेआउट.

2. **🗺️ प्रत्यक्ष गुगल मॅप व उपग्रह दृश्य (Google Maps Live Embed)**:
   - कोठे (Kothe 414606) चे लाइव्ह उपग्रह (Satellite) व मार्ग (Roadmap) दृश्य.
   - थेट Google Maps अ‍ॅपमध्ये उघडण्यासाठी वन-क्लिक जीपीएस नेव्हिगेशन बटण ([Google Maps Link](https://maps.app.goo.gl/4MzqXqfZYtbzAM1K8)).
   - गावातील प्रमुख ठिकाणे: ग्रामपंचायत कार्यालय, जि.प. प्राथमिक शाळा, मारुती व महादेव मंदिर, सेवा सोसायटी, दूध संकलन केंद्र.

3. **🌾 शेतकरी विभाग व थेट बाजारभाव (Farmer Zone & APMC Mandi Rates)**:
   - नेवासा परिसरातील हवामान अंदाज (28°C, वारा, आर्द्रता).
   - थेट APMC मंडी भाव: कांदा, कापूस, सोयाबीन, बाजरी, गहू, ऊस (FRP दर) आणि दूध संकलन दर वाढ/घट निर्देशांकासह.

4. **🏪 स्थानिक व्यवसाय निर्देशिका (Business Directory with WhatsApp)**:
   - किराणा, औषधालय, सलून, शेती सेवा आणि हॉटेल्सची यादी.
   - ग्राहकांसाठी थेट **WhatsApp Chat (`wa.me`)** व कॉल बटण.

5. **📝 ऑनलाइन तक्रार नोंदणी व निवारण (Grievance Redressal Portal)**:
   - रस्ते, पाणी, वीज, गटारे या समस्यांसाठी फोटो व स्थान जोडून तक्रार नोंदवण्याची सोय.
   - प्रत्येक तक्रारीसाठी ऑनलाइन तिकीट क्रमांक (उदा. `#C1024`) आणि लाइव्ह स्टेटस ट्रॅकर (`काम सुरू`, `निवारण झाले`, `तपासणी सुरू`).

6. **🛒 गाव मार्केटप्लेस (Village Marketplace)**:
   - शेतीमाल (कांदा, धान्य), जुनी वाहने/ट्रॅक्टर, घरे भाड्याने देणे व स्थानिक सेवांच्या मोफत जाहिराती.

7. **🌐 त्रिभाषिक सुविधा (Multi-Language Engine)**:
   - एका क्लिकवर संपूर्ण पोर्टल **मराठी**, **English**, किंवा **हिंदी** भाषेत बदलते.

8. **⚡ प्रशासक नियंत्रण कक्ष (Admin Dashboard)**:
   - ग्रामपंचायतीसाठी स्वतंत्र डॅशबोर्ड, आकडेवारी (Users, Complaints, Listings, Events) आणि तक्रारींची स्थिती बदलण्याची सुविधा.

## 📂 प्रोजेक्ट रचना (Project Structure)

```
myvillage/
├── index.html               # मुख्य वेब पोर्टल व मोबाइल अ‍ॅप
├── css/
│   ├── main.css             # डिझाइन टोकन्स, मांडणी व मोबाइल अ‍ॅप स्टाइल्स
│   ├── components.css       # कार्ड्स, गुगल मॅप, मंडी टेबल, तक्रार फॉर्म
│   ├── mobile-simulator.css # स्मार्टफोन फ्रेम व स्क्रीन स्विचर
│   └── admin.css            # प्रशासक डॅशबोर्ड स्टाइल्स
├── js/
│   ├── data.js              # कोठे गाव माहिती, शेती भाव, व्यवसाय डेटा
│   ├── translations.js      # मराठी, इंग्रजी व हिंदी शब्दकोश
│   ├── app.js               # मुख्य कंट्रोलर व नेव्हिगेशन
│   ├── mobile-simulator.js  # मोबाइल अ‍ॅप कंट्रोलर
│   └── admin.js             # प्रशासक डॅशबोर्ड लॉजिक
└── assets/
    └── images/              # उच्च-गुणवत्तेची गाव व शेती चित्रे
```

## 🚀 स्थानिक सर्व्हरवर कसे चालवावे? (How to Run)

कोणत्याही अतिरिक्त लायब्ररीची आवश्यकता नाही (Pure HTML5, Vanilla CSS3 & Vanilla JavaScript).

```bash
# Python द्वारे चालवा:
python -m http.server 3000

# किंवा थेट index.html ब्राउझरमध्ये ओपन करा:
double-click index.html
```

ब्राउझरमध्ये उघडा: `http://localhost:3000`
